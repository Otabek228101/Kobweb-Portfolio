# Retrofit with GitHub REST API.

## Q1
1.	What is Retrofit? Who develops it and which library sends the real HTTP request under it?

*answer*:

Retrofit is a type-safe HTTP client for Android and Java - developed by Square who developed Dagger, Okhttp, etc

## Q2
2.	Why is an API described as an interface in Retrofit? Who writes the implementation and which call gives it to you?

*asnwer*:

In Retrofit, APIs are described as an interface because it makes them simple to model, understand, and consume. By using metadata provided through annotations on these interface methods, Retrofit has enough information to generate working implementations

The implementation of the interface is generated by Retrofit itself, and you obtain this implementation by using the `create()` method on your Retrofit builder

## Q3
3.	Base URL is https://api.github.com/api/v3/. Which URL is called for @GET("/users") and for @GET("users")? Why must base URL end with "/"?

*answer*:

- **`@GET("/users")`:** The URL called is `https://api.github.com/users`. The leading slash makes it an absolute path on the host, meaning any path segment in the base URL (like `api/v3/`) is dropped

- **`@GET("users")`:** The URL called is `https://api.github.com/api/v3/users`. Without the leading slash, the path is relative to the base URL, so the `api/v3/` path is kept

- **Why the base URL must end with a "/":** Retrofit strictly requires the base URL to end with a trailing slash so that relative paths append correctly during URL building

## Q4
4. What is the difference between @Path and @Query? Write one endpoint example for each.

*answer*:
- **`@Path`**: Used to specify a path parameter that replaces a dynamic placeholder (markup) directly inside the URL path itself. 
  Example: `@GET("/users/{login}/repos") suspend fun repos(@Path("login") login: String): List<Repo>`
- **`@Query`**: Used to append query parameters to the end of a URL after the `?` symbol (e.g., `?search=keyword`).
  Example: `@GET("search/repositories") suspend fun search(@Query("q") query: String): SearchResult`

## Q5
5. When do you use @Body and when @Field? Which extra annotation does @Field require?

*answer*:
- **`@Body`**: Used when you want to send a Kotlin/Java object as the complete HTTP request body (typically serialized into JSON for POST or PUT requests).
- **`@Field`**: Used to send data as form-urlencoded (like an HTML form submission).
- **Extra annotation**: `@Field` strictly requires the `@FormUrlEncoded` annotation to be attached to the endpoint method.

## Q6
6. What does a converter factory do? What happens if you add none? Name two converters.

*answer*:
- **Converter factory**: It automatically parses JSON responses from the server into your Kotlin data classes and converts your objects back into JSON for requests.
- **If none is added**: By default, Retrofit can only handle OkHttp's raw `ResponseBody` and `RequestBody`. It will not know how to map JSON to your custom data classes.
- **Two converters**: `GsonConverterFactory` (Gson) and `MoshiConverterFactory` (Moshi).

## Q7
7. Compare execute(), enqueue() and suspend fun. Which one crashes on the Android main thread and why?

*answer*:
- **`execute()`**: Runs synchronously and blocks the calling thread until a response is received.
- **`enqueue()`**: Runs asynchronously on a background thread provided by Retrofit and returns the result via a callback.
- **`suspend fun`**: Uses Kotlin Coroutines. It looks sequential and does not block the thread; it safely suspends and resumes when the data is ready.
- **Which one crashes**: `execute()` will crash on the Android main thread, throwing a `NetworkOnMainThreadException` because it halts the UI thread while waiting for the network response.

## Q8
8. Why do we build Retrofit and OkHttpClient once (ApiInstance) and not in every screen? Give two reasons.

*answer*:
1. **Resource Heavy**: Retrofit and OkHttpClient are expensive to initialize. Building them once and reusing them saves memory and performance.
2. **Centralized Configuration**: It prevents settings from drifting apart. Having a single instance means you have one place to configure base URLs, timeouts, and logging for the entire app.

## Q9
9. What is an interceptor? Where do you add the Authorization header for all requests and what does Authenticator do differently?

*answer*:
- **Interceptor**: A mechanism in the OkHttp chain that can monitor, rewrite, or retry network requests and responses. 
- **Authorization header**: You add it in an Application Interceptor (using `addInterceptor()`), which runs once per call and attaches the token before the request is sent to the network.
- **Authenticator difference**: While an interceptor proactively adds the header to *every* request, an Authenticator reacts *after* receiving a 401 Unauthorized response. It can automatically refresh the token and retry the failed request.

## Q10
10. A suspend call fails. When do you get IOException and when HttpException? Why should you never catch Throwable?

*answer*:
- **`IOException`**: Thrown when there is a network failure, such as no internet connection, a timeout, or a DNS error.
- **`HttpException`**: Thrown when the network call reaches the server, but the server answers with an error status code (like 4xx or 5xx).
- **Never catch `Throwable`**: Catching `Throwable` will accidentally swallow `CancellationException`. This breaks Kotlin Coroutines' cancellation mechanics, causing coroutines to continue running in the background even when they should have been cancelled (like when leaving a screen)
